# 🌐 CAT 2026 — Web Deployment & Online Website Guide

Your application is built as a 100% production-ready, progressive, responsive web application. You can deploy it to the web for free in 2 minutes so anyone in the world can access it on any phone, laptop, or tablet.

---

### 🚀 Option 1: Deploy to Vercel (1-Click Free Hosting)

1. Go to [vercel.com](https://vercel.com) and log in with your GitHub account.
2. Click **"Add New..." → "Project"**.
3. Select your GitHub repository (`cat2026-app` or `MyApplication`).
4. Keep default settings:
   - **Framework Preset**: Vite
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
5. Click **Deploy**!
6. Vercel will give you a live production website URL (e.g. `https://cat2026-app.vercel.app`).

---

### ⚡ Option 2: Deploy to Netlify (Drag & Drop Deployment)

If you don't want to use Git commands:

1. Go to [app.netlify.com/drop](https://app.netlify.com/drop).
2. Open your **Downloads** folder and extract `CAT2026_App_Web.zip` to a folder.
3. Drag and drop the extracted `dist` folder directly onto the Netlify drop zone!
4. Netlify will deploy your website instantly and give you a live URL (e.g. `https://cat2026-master.netlify.app`).

---

### 💻 Option 3: Run Locally on Any PC or Wi-Fi Network

- **Local PC**: Open `http://localhost:5173` in any web browser.
- **Local Wi-Fi Network**: Open `http://10.40.5.135:5173` on any mobile phone or tablet connected to your Wi-Fi.

---

### 📱 PWA (Progressive Web App) Installation

When users open your deployed website on mobile or desktop:
- **Chrome (Android / PC)**: Click **"Install CAT 2026"** in the address bar.
- **Safari (iPhone / iPad)**: Tap Share `⎘` → **"Add to Home Screen"**.
- The website will install as an offline-first app on the user's home screen!
